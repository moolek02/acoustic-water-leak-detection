# Acoustic Water Leak Detection: เอกสารประกอบโปรเจกต์

เอกสารนี้สรุปหลักการตรวจจับท่อน้ำรั่วด้วยเสียง (acoustic leak detection) และอธิบายแบบจำลองที่ใช้ในเว็บ simulation (`index.html`)

## 1. หลักการทำงาน

เมื่อน้ำรั่วออกจากท่อที่มีแรงดัน จะเกิดคลื่นเสียงความถี่ต่ำถึงกลาง (ประมาณหลักร้อยเฮิรตซ์ถึงไม่กี่กิโลเฮิรตซ์) ที่วิ่งไปตามตัวท่อและของเหลวในท่อ ทั้งสองทิศทาง เซนเซอร์ที่ติดตั้งที่จุดสองจุดบนท่อ (เช่น วาล์วหรือหัวดับเพลิง) จะรับเสียงเดียวกันคนละเวลา

วิธีหาตำแหน่งคือวัด **ความต่างเวลาการมาถึง (Time Difference of Arrival, TDOA)** ระหว่างสองเซนเซอร์ แล้วคำนวณระยะ

| สัญลักษณ์ | ความหมาย |
|---|---|
| L | ระยะห่างระหว่างเซนเซอร์ A และ B (m) |
| x | ระยะจากเซนเซอร์ A ถึงจุดรั่ว (m) |
| c | ความเร็วคลื่นเสียงในท่อ (m/s) |
| t_A, t_B | เวลาที่เสียงมาถึงเซนเซอร์ A และ B |

```
t_A = x / c
t_B = (L − x) / c
Δt  = t_B − t_A = (L − 2x) / c
x   = (L − c · Δt) / 2
```

ถ้า Δt เป็นบวก แปลว่าเสียงถึง A ก่อน จุดรั่วจึงอยู่ใกล้ A

## 2. การหาความต่างเวลาด้วย cross-correlation

สัญญาณจากเซนเซอร์ทั้งสองมีรูปร่างคล้ายกันแต่เลื่อนกันตามเวลา ใช้ cross-correlation

```
R(k) = Σₙ sA[n] · sB[n + k]
```

ค่า lag k ที่ทำให้ R(k) สูงสุดคือจำนวนตัวอย่างที่ต่างกันระหว่างสองสัญญาณ แล้วแปลงเป็นวินาทีด้วย Δt = k / fs

**ความละเอียดทางทฤษฎี** เนื่องจาก lag เป็นจำนวนเต็มของตัวอย่าง ความคลาดเคลื่อนขั้นต่ำของตำแหน่งคือ

```
Δx_min ≈ c / (2 · fs)
```

ตัวอย่าง: c = 1200 m/s และ fs = 10 kHz จะได้ Δx ≈ 0.06 m (ประมาณ 6 cm)

## 3. ปัจจัยที่กระทบความแม่นยำ

- **ความเร็วเสียง c** ขึ้นกับวัสดุท่อ (เหล็ก เหล็กหล่อ PVC PE) เส้นผ่านศูนย์กลาง และความดันน้ำ ค่าที่ผิดทำให้ตำแหน่งเพี้ยนโดยตรง
- **อัตราสุ่มตัวอย่าง fs** ยิ่งสูง ความละเอียดยิ่งดี แต่ข้อมูลและการประมวลผลเพิ่มขึ้น
- **สัญญาณรบกวน** เช่น เสียงปั๊ม การไหลของน้ำ เสียงจากการจราจรบนผิวดิน ทำให้พีคของ correlation เตี้ยลงหรือเลื่อนผิดได้
- **ระยะห่างระหว่างเซนเซอร์** ถ้าท่อยาวมากและสัญญาณลดทอนเร็ว correlation อาจอ่อนจนหาพีคไม่เจอ
- **ประเภทเซนเซอร์** ไฮโดรโฟน (hydrophone) วัดแรงดันในน้ำ ส่วนแอคเซเลอโรมิเตอร์ (accelerometer) และจีโอโฟน (geophone) วัดการสั่นของท่อ

## 4. ผลงานและข้อจำกัดที่รายงาน

หมายเหตุ: รายการด้านล่างมาจากผลการค้นหาเบื้องต้น ยังไม่ได้เปิดอ่านต้นฉบับทุกฉบับ ก่อนนำไปอ้างในงานทางการต้องตรวจสอบแหล่งเดิมก่อน

- Correlux C-3 เป็นเครื่อง correlator เชิงพาณิชย์ที่ใช้ไมโครโฟนแบบ piezo กับไฮโดรโฟนที่ติดกับวาล์วหรือหัวดับเพลิง แล้วคำนวณระยะจากเวลาหน่วง ระยะห่างเซนเซอร์ และความเร็วเสียงในท่อ ([เอกสาร CORRELUX C-3 SERIES](https://www.ert.pt/wp-content/uploads/2020/07/CORRELUX-C-3-SERIES_BR_EN_V02.pdf))
- มีงานวิจัยที่วัดไฮโดรโฟน จีโอโฟน และแอคเซเลอโรมิเตอร์พร้อมกันบนชุดทดสอบท่อพลาสติก และเปรียบเทียบผล correlation ([MDPI Sensors, 14(3), 5595](https://0-www-mdpi-com.brum.beds.ac.uk/1424-8220/14/3/5595)) ลิงก์นี้เป็นลิงก์ผ่าน proxy ของมหาวิทยาลัย ควรตรวจกับ mdpi.com โดยตรง
- รีวิวปีประมาณ 2021 ระบุว่าไฮโดรโฟนมีศักยภาพสำหรับการตรวจจับระยะไกลในสภาพที่สัญญาณลดทอนสูง แต่ยังมีปัญหาเรื่องสัญญาณเตือนผิดพลาด รอยรั่วขนาดเล็กหรืออ่อนตรวจจับยาก การระบุตำแหน่งที่แม่นยำ และต้นทุนการเฝ้าระวังระยะยาว (ยังไม่ระบุแหล่งที่มาที่แน่ชัด)
- การทดสอบภาคสนามที่จำลองการรั่ว ไฮโดรโฟนสองตัวห่างกัน 300 m ให้ cross-correlation ที่ไม่ดีและตรวจไม่พบการรั่ว จึงควรระวังเรื่องระยะห่างเซนเซอร์กับความยาวท่อจริง (แหล่งเดียวกับข้อบน ยังไม่ยืนยัน)
- งานปี 2018 ใช้ autocorrelation ของสัญญาณการสั่นสะเทือนจากแอคเซเลอโรมิเตอร์สองตัวและไฮโดรโฟนหนึ่งตัว กับท่อพลาสติกขนาดเล็ก และรายงานผลการทดลองเชิงบวก (แหล่งที่มาที่เชื่อมโยงได้คือ [Applied Sciences, 2018 (DOAJ)](https://doaj.org/article/93b6d4fd71de4ae5b46a140bacb51202) แต่ยังไม่ได้ตรวจว่าเป็นฉบับเดียวกัน)
- แนวคิดการหาตำแหน่งจากความต่างเวลาการมาถึงของเสียงรั่ว และการสุ่มสัญญาณที่ประมาณ 10 kHz ปรากฏในสิทธิบัตรเกี่ยวกับการตรวจจับรั่ว ([US4289019A](https://patents.google.com/patent/US4289019A/Direct))

## 5. แบบจำลองในเว็บ simulation

ไฟล์ `index.html` ไม่ต้องติดตั้งอะไรเพิ่ม เปิดในเบราว์เซอร์ได้เลย

ขั้นตอนของแบบจำลอง:

1. สร้างเสียงรั่วจำลอง: white noise ผ่าน one-pole low-pass แล้วคูณด้วย envelope ที่ดังตอนแรกและค่อย ๆ จาง
2. หน่วงสัญญาณไปยังเซนเซอร์ A และ B ด้วยความล่าช้า x/c และ (L−x)/c (ปัดเป็นจำนวนตัวอย่างเต็ม)
3. เพิ่มสัญญาณรบกวนแบบเกาส์เซียนที่ระดับที่ผู้ใช้ปรับได้
4. คำนวณ cross-correlation ของสองสัญญาณในช่วง lag ที่เป็นไปได้ แล้วหาพีคสูงสุด
5. แปลงเป็นตำแหน่งด้วย x̂ = (L − c·Δt)/2 และเทียบกับตำแหน่งจริง

ค่าที่แสดงบนหน้าจอ: ตำแหน่งจริง ตำแหน่งที่คำนวณได้ Δt ความคลาดเคลื่อน ความละเอียดทางทฤษฎี c/(2fs) และค่า peak correlation

## 6. ข้อจำกัดของ simulation

- เป็นแบบจำลองแบบ non-dispersive (ความเร็วเสียงคงที่ทุกความถี่) ในความเป็นจริงความเร็วขึ้นกับความถี่และวัสดุท่อ
- ไม่มีการลดทอนระหว่างทาง และไม่มีการสะท้อนจากข้อต่อหรือวาล์ว
- สัญญาณรบกวนเป็นแบบสุ่มเกาส์เซียนอย่างเดียว ไม่รวมเสียงปั๊มหรือการไหลจริง
- ใช้สำหรับสาธิตหลักการเท่านั้น ไม่ควรใช้ตัดสินใจเรื่องการซ่อมท่อจริง
