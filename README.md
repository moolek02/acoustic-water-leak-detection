# Acoustic Water Leak Detection

เว็บ simulation และเอกสารประกอบสำหรับการหาตำแหน่งท่อน้ำรั่วด้วยเสียง โดยใช้เซนเซอร์สองตัวที่ปลายท่อและ cross-correlation เพื่อหาความต่างเวลาการมาถึงของเสียงรั่ว

## ไฟล์ในโปรเจกต์

- `index.html`: simulation TDOA แบบ single-file ไม่ต้องติดตั้งอะไรเพิ่ม
- `iot.html`: เครื่องจำลอง AI-IoT ที่มีเซนเซอร์เสียงจำลอง 2 ตัว ส่ง telemetry (JSON) ให้ gateway วิเคราะห์ด้วยโมเดล logistic regression แล้วแจ้งเตือนและประมาณตำแหน่งรั่ว
- `src/signal.js`: สร้างสัญญาณเสียงจำลอง (เสียงรั่ว, เสียงปั๊มพื้นหลัง, noise)
- `src/features.js`: สกัดฟีเจอร์ (cross-correlation, สัดส่วนความถี่สูง, RMS)
- `src/model.js`: logistic regression ที่เทรนด้วย gradient descent ในตัว
- `src/gateway.js`: เทรนโมเดลจากข้อมูลจำลอง วิเคราะห์หน้าต่างสัญญาณ และประมาณตำแหน่งรั่ว
- `src/device.js`: อุปกรณ์ IoT จำลองที่สร้าง telemetry
- `tests/test.mjs`: ทดสอบความแม่นยำ การประมาณตำแหน่ง และอัตราการแจ้งเตือนผิด
- `docs/acoustic-leak-detection.md`: เอกสารหลักการ สูตร ข้อจำกัด และแหล่งอ้างอิง
- `device-sim.html`: จำลองลำดับการทำงานของอุปกรณ์ทีละขั้น สองโปรไฟล์ ได้แก่ LeakNode (AI-IoT, รันโมเดลจริงจาก `src/`) และวิธีเดิมของช่างเดินสำรวจ
- `mockup/leaknode-3d.html`: โมเดล 3 มิติของ LeakNode เทียบกับเครื่องเก่า (ต้องใช้อินเทอร์เน็ตเพื่อโหลด three.js และฟอนต์จาก CDN)

## รันทดสอบ

```
npm test
```

ต้องใช้ Node.js ที่รองรับ ES modules (Node 18 ขึ้นไป) ไม่มี dependency ภายนอก

## วิธีใช้

เปิด `iot.html` หรือ `index.html` ในเบราว์เซอร์ผ่าน GitHub Pages ของ repo นี้ (ถ้าเปิดจากไฟล์โดยตรง `iot.html` อาจโหลดโมดูลไม่ได้ ให้ใช้ local server เช่น `npx serve .`)

ปรับค่าได้ดังนี้

- ความยาวท่อ L, ตำแหน่งรั่ว x, ความเร็วเสียง c, อัตราสุ่มตัวอย่าง fs, ระดับ noise
- ปุ่ม "สุ่มเหตุการณ์รั่วใหม่" จะสุ่มตำแหน่งรั่วใหม่

## สูตรหลัก

```
Δt = (L − 2x) / c
x̂  = (L − c · Δt) / 2
Δx_min ≈ c / (2 · fs)
```

รายละเอียดและแหล่งอ้างอิงอยู่ใน [docs/acoustic-leak-detection.md](docs/acoustic-leak-detection.md)

## ข้อจำกัด

ข้อมูลทั้งหมดเป็นข้อมูลจำลอง โมเดลที่ได้มีความแม่นยำ 100% บนชุดทดสอบจำลองเพราะข้อมูลแยกกันได้ชัดเจน ซึ่งไม่ได้บ่งบอกประสิทธิภาพกับท่อจริง ต้องเก็บข้อมูลจากท่อจริงเพื่อประเมินและเทรนใหม่

เป็นการสาธิตหลักการเท่านั้น ยังไม่ได้จำลองการกระจายความเร็วตามความถี่ การลดทอน การสะท้อนจากข้อต่อ หรือเสียงรบกวนจากปั๊มจริง ห้ามใช้ผลลัพธ์นี้ตัดสินใจเรื่องการซ่อมท่อจริง
